# Budget-aware folded-sign evidence — research candidate

This candidate tests the conditional symmetry of non-tied folded signs, not mean reward variance, population-average utility or downstream RL performance. Each action is a prespecified task sampling contract, with deterministic positive integer cost, and produces a complete matched sign in {-1,0,+1}. The action is chosen before its outcome; the null requires P(+ | past,action)=P(- | past,action). Predictable randomized allocation is allowed, with randomization independent of the current outcome. An action-dependent tie law is allowed. Fixed costs represent rollout counts, not measured GPU time or token costs. Task identifiers prevent reuse but cannot establish the measurement contract.

## Proof and budget oracle

For action j, let W_j,L_j be its non-tied sign counts and E_j=2^(W_j+L_j)/[(W_j+L_j+1) choose(W_j+L_j,W_j)]. Wealth E=product_j E_j starts at one. On a tie it does not change. Under conditional fairness the expected multiplicative update is one, since [E_j(W+1,L)+E_j(W,L+1)]/2=E_j(W,L). The chosen action is predictable; therefore E is a nonnegative martingale. Ville's inequality controls ever crossing 1/alpha at alpha, for all admissible policies and budgets. This is an application of classical betting inference; it is not a general novel theorem.

When independent stationary sign distributions are known, state=(remaining budget, W_j,L_j for each action) suffices for the specified wealth rule. At a crossing, value=1; when no action is affordable, value=0. Otherwise V(b,s)=max_j sum_z P_j(z)V(b-c_j,s+z_j). By backward induction this gives the maximum crossing probability among nonanticipating policies using this particular stopping rule, not among all tests. The solver uses exact rational arithmetic for transition and crossing decisions and is exponential in the number of actions; budget capped at 30.

With signs P_j=(a_j,b_j,t_j), the matched-tie fair null Q_j=((a_j+b_j)/2,(a_j+b_j)/2,t_j) has KL divergence I_j=a_j log(2a_j/(a_j+b_j))+b_j log(2b_j/(a_j+b_j)). Under stationary independent laws, the KL chain rule for the stopped transcript gives D(P||Q)=E_P sum_j N_j I_j <= B max_j I_j/c_j for deterministic budget B. Data processing through the reject indicator gives kl(power, size) <= that bound. In particular if size <= alpha and power >= beta > alpha, B >= kl(beta,alpha)/max_j(I_j/c_j). This is a necessary bound for sign-only tests in this model, not a sufficient budget or a claim that greedy KL is finite-horizon optimal. It excludes information carried by other observables. Related work: Nitinawarat, Atia and Veeravalli, Controlled Sensing for Multihypothesis Testing (2013), https://arxiv.org/abs/1205.0858; Nitinawarat and Veeravalli, non-uniform control cost (2015), https://arxiv.org/abs/1310.1844.

## Reproduction and limits

Python standard library only. Run `python -m unittest -v` and `python benchmark.py`. Nine unit tests passed, including 242 exact null-branch checks and 441 martingale identities, independent recursive oracle comparison and exhaustive adaptive null paths. 1,000 matched synthetic replicates per scenario, four policies, 480 rollout cap. Uniform is round-robin by samples; adaptive is a smoothed information heuristic; posterior uses three initial observations per affordable action then Dirichlet posterior sampling; oracle in benchmark is known-law KL greedy, not the exact DP. The small exact DP at alpha=.2, costs 1 and 2, budget 12, positive sign rates .75 and .9, no ties: optimum 269235829/409600000=.6573140356, KL greedy 1181/2000=.5905, 514 memoized states. This shows the latter is suboptimal even with known laws. The policy variants were developed using the synthetic scenarios, so the comparison is exploratory rather than a held-out test. No real data, GPU, SOTA claim or repository-wide CI. Do not use these results to change a frozen experiment. Real deployment requires immutable task/verifier contracts, independent clusters, predeclared costs and a separate prospective evaluation.
