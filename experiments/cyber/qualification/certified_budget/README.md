# Certified budget planning for folded-sign evidence

Exploratory, known-law model only. This extends the budgeted folded-sign prototype, not the frozen Anarres #97 experiment. Each action has a fixed integer cost and a stationary independent sign law on (+1,-1,0). The objective is the probability of crossing the existing product-of-Beta-mixtures evidence threshold before exhausting the budget, not training accuracy. The exact reference is copied from the previous prototype for independent comparison. No claim of novel general optimization theory or SOTA is made.

## Deterministic certificate

For counts (w,l), wealth is 2^(w+l)/[(w+l+1) choose(w+l,w)]. The current total wealth is the product over actions. For every remaining-budget state:

* Lower bound: choose one affordable action and commit all remaining budget to it. Compute its crossing probability exactly by a two-count recursion, then maximize over actions. At depth d>0 choose the action maximizing the expected child lower bound; this defines a feasible policy which switches to a single-action commitment at its frontier.
* Reachability upper bound: for a fixed number k of additional non-ties, wealth is maximized by one of the all-positive/all-negative paths, because the binomial coefficient is unimodal and the endpoints minimize it over the interval. A max-product knapsack over allocations up to the remaining budget gives an optimistic wealth; if it cannot cross, optimal probability is zero. Ignore probabilities here, including impossible outcomes; that only makes the bound optimistic.
* Expected-wealth upper bound: both possible non-tie wealth ratios sum to 2. Thus under law (p,q,t), the conditional expected multiplier is <= 2 max(p,q)+t. Let G(0)=1 and G(b)=max(1,max_j [(2 max(p_j,q_j)+t_j)G(b-c_j)]). Wealth times G(remaining) is a nonnegative supermartingale under the specified alternative law and any predictable allocation. At stopping after a crossing it is >=1/alpha. Hence crossing probability <=min(1,alpha*wealth*G(b)).
* Bellman backup: maximize expected lower and upper bounds separately over feasible actions, and intersect the upper with the expected-wealth bound. Induction proves the interval contains the optimum. The returned lower is achievable by the depth-limited policy, not by an arbitrary receding-horizon modification. Greater lookahead can narrow bounds; full expansion gives the exact answer. The code uses rational arithmetic for all deterministic decisions. Displayed floats are rounded, not directed-rounding certificates.

This remains exponential in lookahead depth. Budget <=150, lookahead <=30 are implementation guards, not a complexity theorem. Cache sizes bound stored entries, not total runtime or memory usage. `clear()` clears shared method caches. No evidence of uniform speedup.

## Stochastic information-relaxation upper bound

Pre-sample independent future sign streams for every action. A clairvoyant planner can choose prefixes of these streams while retaining the shared budget. For each action compute its maximum wealth over affordable prefixes. An exact rational max-product knapsack determines whether any combination crosses the threshold. Any nonanticipating policy's crossing event is a subset of this clairvoyant event. The expected indicator thus upper-bounds the optimum. Estimate it with independent simulations and the one-sided Hoeffding bound min(1, sample_mean+sqrt(log(1/delta)/(2N))). This is a confidence upper bound, not a deterministic guarantee, conditional on the known model and iid simulation. The fixed-seed PRNG approximates independent draws; exact categorical weights are sampled with integer draws. Five cases each use N=1200 and delta=.01, so Bonferroni gives joint 95% coverage without requiring cross-case independence. The simulation is not real RL training. No prospective outcomes used. Related: Brown, Smith and Sun (2010), Information Relaxations and Duality in Stochastic Dynamic Programs, doi:10.1287/opre.1090.0796. This is a problem-specific application of established information relaxation.

## Reproduction

Python standard library only. `python -m unittest -v`; `python benchmark.py > results.json`; `python reproduce_relaxation.py > relaxation_results.json`. Eight tests passed, including 16 exact-reference cases with multiple depths and full expansion, 80 fixed-count endpoint inequalities, 64 exact pathwise knapsack comparisons, and 512 weighted stream combinations for a tiny relaxation comparison. Runtime values vary. The deterministic interval is sometimes loose and the confidence upper is not uniformly tighter; use the minimum, keeping the confidence qualification.
